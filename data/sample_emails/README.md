# Sample messages

Fictional messages used to demonstrate the email detector. Every address uses an
RFC 2606 reserved domain (`.example`, `.invalid`) or the fictional
`cybersafe.edu` / `example-corp.com` demo organizations. No real person,
company or mailbox is referenced.

Paste the `Subject:` line into the *Subject* field, the body below the blank
line into *Message body*, and the header block into *Raw headers* on
`/email-detector`. The detector never contacts any host named in these files.
